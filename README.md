# Bondi Bootstrap Landing Page

A responsive creative-agency landing page built with Bootstrap, semantic HTML, and custom CSS.

## Highlights

- Responsive Bootstrap navigation and page sections
- Portfolio gallery with interactive hover states
- Services, about, team, blog, newsletter, and contact sections
- Custom color system layered on top of Bootstrap utilities
- Responsive layouts across desktop, tablet, and mobile screens
- Keyboard-visible focus states and reduced-motion support

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Flexbox
- Responsive design
- Font Awesome
